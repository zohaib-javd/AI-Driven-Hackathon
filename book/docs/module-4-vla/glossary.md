# Vision-Language-Action (VLA) Glossary

This glossary defines key terms used throughout the Vision-Language-Action module of the Physical AI & Humanoid Robotics book.

## A

### Action Space
The set of all possible actions that a robot can perform. In VLA systems, actions are typically high-level commands that trigger complex behaviors.

### Autonomous Agent
A system that can perceive its environment and take actions to achieve goals without human intervention. In VLA, this refers to robots that can process voice commands and execute tasks independently.

## C

### Cognitive Planning
The process of using reasoning and knowledge to create a sequence of actions to achieve a goal. In VLA systems, this involves using LLMs to break down high-level commands into executable steps.

### Command Mode
A chatbot interface mode that allows users to execute specific commands like "navigate to Chapter 3" or "show me the ROS 2 architecture diagram."

## D

### Deep Learning
A subset of machine learning using neural networks with multiple layers. Used in VLA for perception tasks like object detection and speech recognition.

### Diagram Rendering
The process of displaying visual elements like Mermaid diagrams, charts, and illustrations in the documentation.

## E

### Embedding
A numerical representation of text, images, or other data in a vector space. Used in RAG systems to enable semantic search.

### End Effector
The device at the end of a robot's arm that interacts with the environment (e.g., gripper, tool).

## F

### Forward Kinematics
The process of calculating the position and orientation of a robot's end effector based on joint angles.

### Full Pipeline
The complete Vision-Language-Action flow: Voice → Language → Reasoning → Action.

## G

### Generative AI
AI systems that can generate new content (text, images, code) based on training data and prompts.

### Grasping
The ability of a robot to securely hold an object using its end effector.

## I

### Isaac Sim
NVIDIA's simulation environment for robotics, providing photorealistic rendering and physics simulation.

### Isaac ROS
ROS 2 packages that provide GPU-accelerated perception and simulation capabilities.

### Inverse Kinematics
The process of calculating the joint angles required to position a robot's end effector at a desired location.

## L

### Large Language Model (LLM)
Advanced AI models trained on vast amounts of text to understand and generate human-like language.

### Language Processing
The conversion and interpretation of natural language commands into structured robot instructions.

### Locomotion
The ability of a robot to move from one location to another.

## M

### Manipulation
The ability of a robot to interact with objects in its environment, including grasping, moving, and repositioning objects.

### Model-Agnostic
Design that works with multiple different AI models (OpenAI, Claude, LLaMA) without requiring specific implementation changes.

### MPC (Model Predictive Control)
A control strategy that uses a model of the system to predict future behavior and optimize control actions.

## N

### Nav2
The navigation stack for ROS 2, providing path planning, obstacle avoidance, and robot control capabilities.

### Natural Language Processing (NLP)
The field of AI focused on enabling computers to understand, interpret, and generate human language.

### Neural Network
A machine learning model inspired by the human brain, used for complex pattern recognition tasks.

## O

### Object Detection
The computer vision task of identifying and localizing objects within an image or scene.

### OpenAI API
A set of interfaces provided by OpenAI for accessing their AI models, including GPT and embedding models.

## P

### Perception Pipeline
The sequence of processing steps that convert raw sensor data into meaningful information about the environment.

### Planning Pipeline
The sequence of steps that convert high-level goals into executable actions for the robot.

### Point Cloud
A set of data points in 3D space, typically generated by LiDAR or depth sensors.

### Pose Estimation
Determining the position and orientation of objects or the robot itself in 3D space.

## R

### RAG (Retrieval-Augmented Generation)
A technique that combines information retrieval with language model generation to provide more accurate and contextually relevant responses.

### Reasoning Pipeline
The system that processes natural language commands and generates logical action sequences.

### Robot Operating System (ROS)
A flexible framework for writing robot software, providing hardware abstraction and message passing.

### ROS 2
The second generation of the Robot Operating System, providing improved architecture and real-time capabilities.

### ROS Bridge
A component that connects ROS 2 with other systems like Isaac Sim or Unity.

## S

### Safety Guardrails
Mechanisms to prevent unsafe robot behaviors, especially important for LLM-controlled robots.

### Semantic Search
A search approach that understands the meaning and context of queries rather than just keyword matching.

### Sensor Fusion
The process of combining data from multiple sensors to create a more accurate and reliable understanding of the environment.

### Speech-to-Text
The conversion of spoken language into written text, often using models like OpenAI's Whisper.

### State Machine
A model of computation used to design systems that can be in exactly one of a finite number of states at any given time.

## T

### Task Breakdown
The process of decomposing high-level goals into specific, executable steps.

### Transformer Architecture
The neural network architecture that powers most modern LLMs, using attention mechanisms to process sequences.

### Trajectory Planning
The process of determining a sequence of positions and movements for a robot to follow.

## V

### VLA (Vision-Language-Action)
The paradigm combining computer vision, natural language processing, and robotic action in a unified system.

### Voice Command
A spoken instruction that is processed by speech recognition systems to control robot behavior.

### Voice-to-Action Pipeline
The complete system flow from receiving a voice command to executing the corresponding robot action.

### Vision Processing
The analysis and interpretation of visual data from cameras and other optical sensors.

## W

### Whisper API
OpenAI's speech recognition API that converts audio to text.

### Workspace
The 3D space in which a robot can operate and manipulate objects.

## Z

### Zero-Shot Learning
The ability of a model to perform tasks it hasn't been explicitly trained on by leveraging its general understanding.
